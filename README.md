# Muhammad Imran Rasheed - Luxury Portfolio Website

A modern, high-performance personal portfolio website for **Muhammad Imran Rasheed**, crafted in an ultra-luxurious **Obsidian Black & Royal Gold** design theme.

---

## 🌟 Key Highlights & Design Aesthetic

- **Color Palette**: Deep Obsidian (`#070709`), Dark Charcoal (`#0d0d12`), Metallic Royal Gold (`#D4AF37`), Radiant Champagne (`#FFF3B0`), and Deep Antique Gold (`#AA771C`).
- **Interactive Stardust Particles**: Subtle, GPU-accelerated constellation particle canvas that reacts to mouse movement.
- **Glassmorphic Depth**: Frosted backdrop-filters, illuminated golden gradient borders, and 3D card tilt physics.
- **100% Responsive**: Tailored fluid typography and adaptive grids across ultra-wide monitors, laptops, tablets, and smartphones.
- **Zero Heavy Dependencies**: Pure semantic HTML5, modern vanilla CSS3 (CSS variables, animations), and vanilla ES6+ JavaScript. Fast load times, 100/100 performance potential.

## 💻 How to Run Locally

You can preview the website instantly using any local static file server:

### Option 1: Direct File Opening
Double-click `index.html` to open it directly in any modern web browser (Google Chrome, Microsoft Edge, Firefox, Safari).

### Option 2: Using Node.js (npx serve)
```bash
npx serve .
```
Then visit `http://localhost:3000`.

### Option 3: Using Python
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
